# EarnIt App — Project Context

## What this is
EarnIt is a parenting app for tracking kids' chores and daily behavior,
built around an XP/leveling/rewards system. Kids earn XP from chores and
parent-filed daily behavior reports, level up, earn credits, and convert
credits into real allowance money (parent-approved). There's also an
in-app Store where XP can be spent directly on smaller rewards.
